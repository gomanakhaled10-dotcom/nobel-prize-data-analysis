# Nobel Prize Dataset Analysis

## Project Overview
This project explores Nobel Prize data to identify patterns, trends, and insights using Python and exploratory data analysis.

## Objectives
- Inspect and understand the dataset.
- Explore Nobel Prize distributions and trends.
- Analyze relevant features and relationships.
- Visualize findings using charts and graphs.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Data visualization
5. Interpretation of findings
